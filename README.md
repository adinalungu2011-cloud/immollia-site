# Site IMMOLLIA

Site vitrine de l'association IMMOLLIA (immollia.fr). Site statique : HTML, CSS, JavaScript, sans outil de construction.

- `index.html` : page d'accueil
- `zone-de-genie.html` : le parcours Zone de Génie
- `annuaire.html` : annuaire des membres (liste `MEMBERS` en bas du fichier)
- `assets/` : styles, script, logo, portraits, logos partenaires
- `A-VALIDER.md` : points restant à valider avant publication

Hébergement : compte o2switch (dossier `~/immollia.fr`, domaine supplémentaire), mis à jour par `git pull` à chaque publication.
